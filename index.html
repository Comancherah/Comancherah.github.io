Featured Project

MTG Match Tracker (v1.0.0)
Shipped • Windows Installer

A standalone Windows desktop telemetry and match-analytics application for Magic: The Gathering and MTG Arena, built from the ground up with Python, pandas, and tkinter.

  • Live JSON Log Parser (arena_parser.py): Automatically scans Player.log JSON events to extract deck names, formats, turn counts, and match results in one click.
  • Multi-Tier Analytics Engine: Aggregates CSV match ledgers via pandas to compute win rates, mana-curve efficiency ratios, and opponent nemesis trends.
  • Production Packaging: Compiled into a standalone .exe with PyInstaller and wrapped in an Inno Setup Windows installer using %LOCALAPPDATA% user-profile storage.
